## What to build

The FAQ answers only questions that still apply to the current add-on, and only those that no other page answers better.

Today the page has two questions:

- JavaScript errors like "setOption is not a function": the answer names the Spring Boot property `vaadin.whitelisted-packages`. Check which property current Vaadin versions use, and whether the linked Known Issues section still exists and applies.
- `DatesRenderedEvent` not fired when an option changes the view: `allowDatesRenderEventOnOptionChange` still exists. Check that the answer still describes the behavior of 8.0, and whether it belongs on the topic page of event listeners from #319 instead.

Then look for questions worth adding, for example from recurring GitHub issues labeled `Q&A`.
