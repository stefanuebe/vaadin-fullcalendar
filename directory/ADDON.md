# FullCalendar for Flow
This add-on integrates the [FullCalendar](https://fullcalendar.io/) JavaScript library as a Flow component. Version 8 is
based on the FullCalendar library 7.1. Versions 6 and 7 are based on the 6.x library.

## Requirements / versions / support
There are several versions of the add-on:
* Version 8, based on Vaadin 25.3 / Java 21
* Version 7, based on Vaadin 25 / Java 21
* Versions 6.4 and 6.5, based on Vaadin 24.9 / Java 17
* Version 6.3 and before, based on Vaadin 14 / Java 11 (works up to Vaadin 24, no longer supported)

Version 8 is the current version. Version 7 gets bug fixes from version 8 where they apply. Version 6.5 gets
fixes only through [Vaadin Support Credits](https://vaadin.com/pricing). Other versions are not supported. If you need a fix for
such a version, feel free to fork the project.

To get started, see [Getting Started](https://github.com/stefanuebe/vaadin-fullcalendar/wiki/Getting-Started) and the
[Samples](https://github.com/stefanuebe/vaadin-fullcalendar/wiki/Samples) in the wiki.

## FullCalendar Scheduler for Flow add-on
This separate add-on extends the **FullCalendar for Flow** add-on with the FullCalendar Premium Plugins / Scheduler, which provide
additional resource-based views (Timeline View and Vertical Resource View).

For information about the Scheduler (functionality, features, license information, etc.)
visit https://fullcalendar.io/pricing.

### License information
Please be aware that the FullCalendar Scheduler library this add-on is based on has a different license model
than the FullCalendar library. For details about the license, visit https://fullcalendar.io/license.

**The scheduler add-on does not provide any commercial license for the Scheduler. The MIT license covers only
this add-on's own files, not the FullCalendar Scheduler files it uses.**
